# SENDER DESIGN DNA

## 1. COLOR
- BLANCO: `#FFFFFF`
- AZUL SENDER: `#1E73BE`
- GRIS OSCURO (Fondo principal/texto técnico): `#494949`
- AZUL CLARO (Acentos/Señales): `#0085B2`

## 2. TYPOGRAPHY
- Técnica, geométrica, de alto contraste. Sans-serif limpia (Inter/Space Grotesk) y Monoespaciada para datos técnicos.

## 3. GRID & SPACING
- Grid asimétrico de 12 columnas.
- Espaciado masivo (Whitespace as a feature).

## 4. 3D & MOTION
- Minimalista, técnico, representación de ondas (waveforms) y campos espaciales de RF. Cero esferas genéricas.
- Movimiento cinemático y lento (GSAP + Lenis).

## 5. ANTI-SLOP RULES
- NO colores inventados.
- NO marketing clichés.
- NO glassmorphism excesivo ni gradients aleatorios.
